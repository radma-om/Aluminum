# إشعارات أوامر العمل + Flow Builder للرقم 90660005

كل ما في هذا الملف يُنشأ في **حساب القوالب الجديد (90660005)** في MazBot.

## أولاً: القوالب الأربعة (WhatsApp ← Templates ← Add New)

لكل قالب:
- **الفئة:** Utility — **اللغة:** Arabic — **بدون Header**.
- **زر واحد:** Quick Reply نصه بالضبط: `إيقاف الإشعارات 48 ساعة`
- انسخ النص حرفياً ولا تغيّر ترتيب المتغيرات.

### 1) موعد التركيب — `MAZBOT_WO_SCHEDULED_TEMPLATE_ID`
**الاسم:** `radma_wo_scheduled`
```
مرحباً {{1}}،
تم تحديد موعد {{2}} 📅
الموعد: {{3}}
الفني: {{4}}
لتتبع طلبكم: {{5}}
للاستفسار راسلونا على 90660001.
```
الأمثلة: {{1}} خالد | {{2}} تركيب البوابة | {{3}} الأحد 2026-11-22 — 10:00 | {{4}} أحمد | {{5}} https://calcshutter.radma.co/t/abc123

### 2) الفني في الطريق — `MAZBOT_WO_ONTHEWAY_TEMPLATE_ID`
**الاسم:** `radma_wo_on_the_way`
```
مرحباً {{1}}،
الفني {{2}} في الطريق إليكم الآن لتنفيذ {{3}} 🚚
لتتبع طلبكم: {{4}}
نرجو التواجد في الموقع، وللاستفسار راسلونا على 90660001.
```
الأمثلة: {{1}} خالد | {{2}} أحمد | {{3}} تركيب البوابة | {{4}} https://calcshutter.radma.co/t/abc123

### 3) بدء العمل — `MAZBOT_WO_STARTED_TEMPLATE_ID`
**الاسم:** `radma_wo_started`
```
مرحباً {{1}}،
بدأ الفني {{2}} العمل على {{3}} 🔧
لتتبع طلبكم: {{4}}
سنبلغكم فور الانتهاء.
```
الأمثلة: {{1}} خالد | {{2}} أحمد | {{3}} تركيب البوابة | {{4}} https://calcshutter.radma.co/t/abc123

### 4) اكتمال العمل — `MAZBOT_WO_DONE_TEMPLATE_ID`
**الاسم:** `radma_wo_done`
```
مرحباً {{1}}،
تم إنجاز {{2}} بنجاح ✅
المتبقي على الفاتورة: {{3}} ر.ع
لتتبع طلبكم والفاتورة: {{4}}
شكراً لاختياركم رادما.
```
الأمثلة: {{1}} خالد | {{2}} تركيب البوابة | {{3}} 120.000 | {{4}} https://calcshutter.radma.co/t/abc123

**متى تُرسل:**
| القالب | متى |
|---|---|
| موعد التركيب | المكتب يحدد الموعد أو يغيّره (أو يغيّر الفني) مع علامة «إبلاغ العميل على واتساب بالموعد» |
| في الطريق | الفني يضغط «في الطريق» في بطاقة أمر العمل |
| بدء العمل | الفني يضغط «بدأت العمل» |
| اكتمال العمل | الفني أو المكتب يسجّل «اكتمل» (لا يُرسل لزيارة خدمة فُتحت وأُغلقت فوراً — فاتورتها تُرسل) |

قالب غير مضبوط = لا يُرسل شيء (بلا خطأ). والمدير يوقف الكل من «الربط» ← «إشعارات أوامر العمل للعميل».

## ثانياً: Webhook الحساب الجديد (Setting ← Webhook)

حتى يعمل زر **«إيقاف الإشعارات 48 ساعة»** وخيار **«تتبع طلبي»**:

1. في Hostinger أضف `MAZBOT_TEMPLATES_WEBHOOK_SECRET` = نص عشوائي طويل (16 حرفاً أو أكثر — اختره أنت) وأعد تشغيل التطبيق.
2. في لوحة النظام ← «الربط»: يظهر **رابط Webhook حساب القوالب** — انسخه.
3. في MazBot (الحساب الجديد) ← Setting ← Webhook ← أضف رابطاً:
   - الرابط: المنسوخ من الخطوة 2.
   - الأحداث: `message.received` و `interactive.selected`.
4. انسخ **سرّ التوقيع (Signing secret)** الذي يظهر لهذا الرابط وضعه في Hostinger: `MAZBOT_TEMPLATES_SIGNING_SECRET`، ثم أعد التشغيل.

لا تغيّر Webhook الحساب القديم — يبقى للرسائل الواردة والمساعد.

## ثالثاً: Flow Builder للرقم 90660005 (WhatsApp ← Flow Builder ← Create)

**البداية:** كلمات مفتاحية بمطابقة جزئية (Contains): `مرحبا`، `السلام`، `هلا`، `قائمة`، `ابدأ`، `hi`، `menu`.

**العقدة 1 — Button (رسالة بأزرار، 3 أزرار حد واتساب):**
```
أهلاً بك في رادما 👋
كيف نخدمك اليوم؟

🤖 للأسئلة السريعة والأسعار تحدّث مع مساعدنا الذكي:
https://wa.me/96890660002
```
الأزرار:
1. `خدمة العملاء` ← العقدة 2
2. `حاسبة البوابات` ← العقدة 3
3. `تتبع طلبي` ← **لا تربطه بعقدة** (النظام يرد عليه تلقائياً بروابط طلبات العميل عبر الـWebhook)

**العقدة 2 — Text (خدمة العملاء):**
```
يسعدنا خدمتك 🙏
راسل فريق خدمة العملاء مباشرة:
https://wa.me/96890660001
أوقات العمل: السبت – الخميس، 8 ص – 6 م.
```

**العقدة 3 — Text (حاسبة البوابات):**
```
احسب سعر بوابتك خلال دقيقة 🧮
https://calcshutter.radma.co
اختر النوع والمقاس واللون، ويصلك السعر وفريقنا يتواصل معك.
```

**«تتبع»:** العميل يضغط الزر أو يكتب «تتبع» ← النظام يرد بروابط فواتيره وطلباته المفتوحة (من رقم جواله). إذا لم يجد شيئاً يوجّهه لخدمة العملاء.

(عدّل أوقات العمل ورابط الحاسبة حسب الواقع.)
