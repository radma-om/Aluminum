# قوالب واتساب للعملاء (MazBot)

ثلاثة قوالب تُرسل للعميل من رقم الشركة بزر من الموظف. أنشئها في MazBot (أو WhatsApp Manager):

- **الفئة:** Utility (خدمية) — لا Marketing.
- **اللغة:** العربية (`ar`).
- انسخ النص كما هو. `{{1}}` و`{{2}}` … متغيرات يملؤها النظام بالترتيب المكتوب تحت كل قالب.
- لا تغيّر ترتيب المتغيرات، ولا تضع متغيراً في أول النص أو آخره (ميتا ترفض ذلك).
- بعد الاعتماد انسخ **رقم القالب (Template ID)** من MazBot وضعه في متغير البيئة المذكور على Hostinger، ثم أعد تشغيل التطبيق.

---

## 1) الفاتورة صدرت — `MAZBOT_INVOICE_TEMPLATE_ID`

**اسم مقترح:** `radma_invoice_issued`

```
مرحباً {{1}}،
صدرت فاتورتكم رقم {{2}} من رادما.
الإجمالي: {{3}} ر.ع
المدفوع: {{4}} ر.ع
المتبقي: {{5}} ر.ع
لعرض الفاتورة وتحميلها: {{6}}
شكراً لتعاملكم معنا.
```

| المتغير | القيمة | مثال للمراجعة (Sample) |
|---|---|---|
| {{1}} | اسم العميل | خالد |
| {{2}} | رقم الفاتورة | INV-2026-0042 |
| {{3}} | الإجمالي شامل الضريبة | 420.00 |
| {{4}} | المدفوع | 200.00 |
| {{5}} | المتبقي | 220.00 |
| {{6}} | رابط ملف الفاتورة PDF | https://example.com/invoices/INV-2026-0042.pdf?k=abc |

---

## 2) تأكيد دفعة — `MAZBOT_PAYMENT_TEMPLATE_ID`

**اسم مقترح:** `radma_payment_received`

```
مرحباً {{1}}،
استلمنا دفعتكم بمبلغ {{2}} ر.ع للفاتورة رقم {{3}}.
مجموع المدفوع: {{4}} ر.ع
المتبقي: {{5}} ر.ع
لعرض الفاتورة: {{6}}
شكراً لكم.
```

| المتغير | القيمة | مثال |
|---|---|---|
| {{1}} | اسم العميل | خالد |
| {{2}} | مبلغ هذه الدفعة | 200.00 |
| {{3}} | رقم الفاتورة | INV-2026-0042 |
| {{4}} | مجموع المدفوع حتى الآن | 200.00 |
| {{5}} | المتبقي | 220.00 |
| {{6}} | رابط الفاتورة PDF | https://example.com/invoices/INV-2026-0042.pdf?k=abc |

---

## 3) تذكير بالمتبقي — `MAZBOT_BALANCE_TEMPLATE_ID`

**اسم مقترح:** `radma_balance_reminder`

```
مرحباً {{1}}،
نذكّركم بأن المتبقي على الفاتورة رقم {{2}} هو {{3}} ر.ع.
لعرض الفاتورة: {{4}}
يسعدنا تواصلكم لأي استفسار.
```

| المتغير | القيمة | مثال |
|---|---|---|
| {{1}} | اسم العميل | خالد |
| {{2}} | رقم الفاتورة | INV-2026-0042 |
| {{3}} | المتبقي | 220.00 |
| {{4}} | رابط الفاتورة PDF | https://example.com/invoices/INV-2026-0042.pdf?k=abc |

---

## 4) عرض السعر جاهز — `MAZBOT_QUOTE_TEMPLATE_ID`

**اسم مقترح:** `radma_quote_ready` — الفئة Utility، بدون Header ولا أزرار.

```
مرحباً {{1}}،
عرض السعر رقم {{2}} جاهز 📄
الإجمالي: {{3}} ر.ع
ساري حتى: {{4}}
لمراجعة البنود والموافقة على العرض: {{5}}
للاستفسار راسلونا على 90660001.
```

| المتغير | القيمة | مثال |
|---|---|---|
| {{1}} | اسم العميل (الاسم الأول) | خالد |
| {{2}} | رقم العرض | Q261119-56FFAD |
| {{3}} | الإجمالي (أو «من – إلى» لعرض بنطاق سعر) | 363.96 |
| {{4}} | ساري حتى | 2026-12-04 |
| {{5}} | رابط صفحة العرض (مراجعة وموافقة) | https://calcshutter.radma.co/q/abc123 |

يُرسل من نافذة العرض («إرسال العرض للعميل من رقم الشركة»)، ويسأل النظام عنه بعد حفظ عرض جديد. بعد الإرسال تصبح حالة العرض «تم التواصل».

## حساب مستقل للقوالب (اختياري)

إن كانت القوالب في **حساب MazBot آخر** (رقم مخصص للقوالب المعتمدة — مثلاً الحساب القديم لا يرسل القوالب بسبب الدفع)، تُرسل منه **كل القوالب**: قوالب الحاسبات لأرقام المبيعات وقوالب العملاء. ويبقى الحساب القديم للرسائل الواردة ومتابعة العملاء والمساعد والردود النصية:

| المتغير | ما هو |
|---|---|
| `MAZBOT_TEMPLATES_API_KEY` | مفتاح API من الحساب الجديد (API ← المفتاح) |
| `MAZBOT_TEMPLATES_STAFF_EMAIL` | بريد **موظف** في الحساب الجديد (Team Member) — حساب المالك لا يعمل مع API |
| `MAZBOT_TEMPLATES_STAFF_PASSWORD` | كلمة مرور ذلك الموظف |

وكل أرقام القوالب تكون من **الحساب الجديد**: قوالب العملاء الثلاثة، **وقوالب الحاسبات** (`MAZBOT_TEMPLATE_ID` و`MAZBOT_OVERHEAD_TEMPLATE_ID` و`MAZBOT_MOTORS_TEMPLATE_ID`) — أنشئها في الحساب الجديد بنفس نصوص الحساب القديم وترتيب متغيراتها (11 و8 و6)، ثم ضع أرقامها الجديدة. لا تغيّر `MAZBOT_API_KEY` ولا `MAZBOT_STAFF_*` ولا `MAZBOT_WEBHOOK_SECRET` — هي للحساب القديم.

## متغيرات البيئة على Hostinger (الأسماء فقط — القيم من حسابك)

| المتغير | ما هو |
|---|---|
| `MAZBOT_INVOICE_TEMPLATE_ID` | رقم قالب «الفاتورة صدرت» بعد الاعتماد |
| `MAZBOT_PAYMENT_TEMPLATE_ID` | رقم قالب «تأكيد دفعة» |
| `MAZBOT_BALANCE_TEMPLATE_ID` | رقم قالب «تذكير بالمتبقي» |
| `MAZBOT_API_KEY`، `MAZBOT_STAFF_EMAIL`، `MAZBOT_STAFF_PASSWORD` | موجودة من قبل — بعد تغيير المفتاح ضع الجديد هنا |
| `MAZBOT_WEBHOOK_SECRET` | موجود من قبل — غيّره من MazBot وضعه هنا |

وفي لوحة النظام: **الإعدادات ← رابط النظام العام** يجب أن يكون عنوان الموقع بـ `https://` — منه يُبنى رابط الفاتورة الذي يصل العميل.

**بلا قالب:** يرسل النظام نصاً عادياً بنفس الكلمات، وهذا يصل فقط إذا راسلكم العميل خلال آخر 24 ساعة (قاعدة واتساب). لذلك القوالب هي الطريقة المضمونة.
